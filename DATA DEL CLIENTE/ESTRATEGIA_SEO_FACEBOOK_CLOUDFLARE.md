## 4. Guía Paso a Paso: Subir a GitHub y Publicar GRATIS en Cloudflare Pages

El proyecto ya está 100% configurado y compilado en `D:\WHA MOUNTAIN\PAGINA WEB` con cabeceras de seguridad bancarias/empresariales (`public/_headers`) y rutas SPA (`public/_redirects`).

### Paso 1: Subir el proyecto a tu cuenta de GitHub
1. Crea un repositorio nuevo en [GitHub](https://github.com/new) llamado por ejemplo `wha-mountain-web` (puede ser **Privado** o **Público**, Cloudflare Pages funciona gratis con ambos).
2. Abre una terminal (PowerShell o Git Bash) dentro de la carpeta `D:\WHA MOUNTAIN\PAGINA WEB` y ejecuta:
   ```powershell
   cd "D:\WHA MOUNTAIN\PAGINA WEB"
   git init
   git add .
   git commit -m "Lanzamiento web oficial WHA MOUNTAIN Peru - 79 productos"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/wha-mountain-web.git
   git push -u origin main
   ```

### Paso 2: Conectar GitHub con Cloudflare Pages (Hosting Global Gratuito e Ilimitado)
1. Inicia sesión en [Cloudflare Dashboard](https://dash.cloudflare.com/) (plan gratuito).
2. En el menú izquierdo, ve a **Compute (Workers & Pages)** $\rightarrow$ **Pages** $\rightarrow$ **Create application** $\rightarrow$ **Connect to Git**.
3. Autoriza tu cuenta de GitHub y selecciona el repositorio `wha-mountain-web`.
4. En la pantalla **Set up builds and deployments**, coloca exactamente esta configuración:
   - **Production branch**: `main`
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
5. Haz clic en **Save and Deploy**. En menos de 60 segundos tu web estará en línea con certificado SSL HTTPS automático y CDN global en más de 300 ciudades (incluyendo el nodo de Cloudflare en Lima, Perú, para carga en menos de 0.3 segundos).

### Paso 3: Seguridad Avanzada en Cloudflare (Ya incluida + WAF Recomendado)
1. **Cabeceras HTTP de Seguridad Automáticas (`public/_headers`)**:
   Cloudflare Pages leerá automáticamente el archivo `public/_headers` que hemos creado, activando:
   - `Strict-Transport-Security (HSTS)`
   - `Content-Security-Policy (CSP)` contra inyección de scripts (XSS)
   - `X-Frame-Options: DENY` contra robo de clics (Clickjacking)
   - `X-Content-Type-Options: nosniff`
   - Caché inmutable de 1 año para todas las imágenes de productos (`/images/*`), logrando máxima puntuación (95–100) en Google PageSpeed Insights.
2. **Si conectas un dominio propio (ej. `whamountainperu.com`) en Cloudflare**:
   - Ve a **SSL/TLS** $\rightarrow$ selecciona modo **Full (strict)** y activa **Always Use HTTPS**.
   - Ve a **Security** $\rightarrow$ **Bots** y activa **Bot Fight Mode** (Gratuito) para bloquear scrapers automatizados.
